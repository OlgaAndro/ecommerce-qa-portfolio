# QA Portfolio: E-commerce Platform Testing

Комплексное ручное тестирование веб-приложения (UI, API, БД). Данный репозиторий содержит артефакты тестирования, разработанные для демонстрации навыков обеспечения качества на реальном развернутом стенде.

## 🎯 Цель проекта
Провести функциональное, UI/UX и API-тестирование полного цикла заказа (E2E), а также валидацию целостности данных в базе данных.

## 🛠️ Стек и инструменты
- **Типы тестирования:** Функциональное, UI/UX, Кроссбраузерное, API (REST), Регрессионное.
- **Инструменты:** Postman (коллекции API), DevTools (Network, Console, Elements), phpMyAdmin (SQL-запросы), Markdown.
- **Окружение:** 
  - OS: Windows 10 / Android 13+
  - Browsers: Chrome (latest), Firefox (latest), Yandex Browser.

## 📂 Структура репозитория
- `test-artifacts/` — Чек-листы и детальные тест-кейсы (E2E сценарии).
- `api-tests/` — Экспортированная коллекция Postman для тестирования REST API.
- `sql-validation/` — Примеры SQL-запросов для проверки целостности данных после действий в UI.
- `bug_reports.md` — Документированные дефекты с шагами воспроизведения и доказательствами.

## 🌐 О тестовом окружении
Тестирование проводилось на временном staging-стенде (OpenCart/WooCommerce). 
Поскольку среда является временной, прямые ссылки на стенд могут быть неактивны. 
**Вся доказательная база сохранена в репозитории:**
- 📸 Скриншоты UI/UX дефектов и состояний интерфейса.
- 🎥 Короткие видео-демонстрации (E2E-сценарии, работа с API в Postman, запросы к БД).
- 📄 Экспортированные JSON-коллекции Postman и текстовые файлы с SQL-запросами.
