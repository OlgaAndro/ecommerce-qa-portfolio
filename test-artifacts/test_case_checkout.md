# Тест-кейс: TC-001 — Успешное оформление заказа

**ID:** TC-001  
**Модуль:** Оформление заказа (Checkout)  
**Приоритет:** High  
**Предусловия:**  
1. Пользователь зарегистрирован и авторизован.  
2. В каталоге есть минимум 1 товар с статусом "В наличии".  
3. Корзина пуста.  

---

## Шаги выполнения

| № | Действие | Ожидаемый результат |
|---|----------|---------------------|
| 1 | Открыть витрину магазина | Загружается главная страница, отображается каталог |
| 2 | Открыть карточку любого товара | Отображается название, цена, изображение, кнопка "В корзину" |
| 3 | Нажать "В корзину" | Товар добавлен, счетчик корзины увеличился на 1 |
| 4 | Перейти в корзину | Отображается добавленный товар, цена, кнопка "Оформить" активна |
| 5 | Нажать "Оформить" | Открывается форма оформления заказа |
| 6 | Заполнить поле "Имя" валидным значением | Поле принято, ошибок валидации нет |
| 7 | Заполнить поле "Телефон" в формате +7XXXXXXXXXX | Поле принято |
| 8 | Заполнить поле "Адрес доставки" | Поле принято |
| 9 | Нажать кнопку "Подтвердить заказ" | Отображается страница/сообщение об успешном оформлении, присвоен Order ID |
| 10 | Перейти в ЛК → "Мои заказы" | Новый заказ отображается в списке со статусом "Новый" |

---

## Постусловия
- Заказ создан в базе данных.
- В админ-панели появился новый заказ с тем же Order ID.
